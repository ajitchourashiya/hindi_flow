# Changelog

All notable changes to HindiFlow are documented in this file.

## 0.1.1

- Added a built-in default API endpoint so translation can be used without mandatory initialization.
- Kept support for configuring a custom API base URL.
- Improved API URL validation and request configuration.
- Updated package documentation with installation instructions, usage examples, caching, JSON translation, and error handling.
- Improved code formatting and analyzer suggestions.

## 0.1.0

- Initial release of HindiFlow.
- Added English-to-Hindi text translation through the HindiFlow API.
- Added JSON translation support for nested string values.
- Added the `HindiText` widget for displaying translated text.
- Added in-memory and persistent caching support.
- Added configurable API base URL.
